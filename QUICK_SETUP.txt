# QUICK SETUP COMMANDS

## Copy and paste these commands into Supabase SQL Editor

### Step 1: Run Permissions & RLS Script
Go to: `supabase/PERMISSIONS_AND_RLS.sql` and run all the SQL code

### Step 2: Create Admin User(s)

#### For admin@pencilroyal.com:
```sql
INSERT INTO user_roles (user_id, role)
SELECT id, 'admin'
FROM auth.users
WHERE email = 'admin@pencilroyal.com'
ON CONFLICT (user_id) DO NOTHING;
```

#### For ss@gmail.com:
```sql
INSERT INTO user_roles (user_id, role)
SELECT id, 'admin'
FROM auth.users
WHERE email = 'ss@gmail.com'
ON CONFLICT (user_id) DO NOTHING;
```

#### For admin@test.com:
```sql
INSERT INTO user_roles (user_id, role)
SELECT id, 'admin'
FROM auth.users
WHERE email = 'admin@test.com'
ON CONFLICT (user_id) DO NOTHING;
```

#### OR Add Multiple at Once:
```sql
INSERT INTO user_roles (user_id, role)
SELECT id, 'admin'
FROM auth.users
WHERE email IN ('admin@pencilroyal.com', 'ss@gmail.com', 'admin@test.com')
ON CONFLICT (user_id) DO NOTHING;
```

### Step 3: Verify Admin Users Were Created
```sql
SELECT ur.user_id, ur.role, au.email
FROM user_roles ur
JOIN auth.users au ON ur.user_id = au.id
WHERE ur.role = 'admin'
ORDER BY au.email;
```

Should show all your admin email addresses.
